# Agent instructions

This repository is the `lyrasoft/luna` PHP package (a CMF layer on top of
Windwalker Core and Unicorn), not a host application. Follow the
package-specific guidance in
[`.github/copilot-instructions.md`](.github/copilot-instructions.md) when
working here.

Keep changes scoped to this package. Editing a consuming host application is
allowed when the task requires it. Before editing any other Composer-installed
package, ask the user for confirmation.
